

# 🏥 مركز نور الحياة - Noor Al-Hayat Medical Center

## المرحلة الأولى: الصفحة الرئيسية + المقالات + البنية الأساسية

### 1. البنية التحتية والتصميم
- نظام ألوان طبي هادئ (أزرق طبي + أخضر + أبيض) مع تصميم Mobile First
- دعم ثنائي اللغة (عربي RTL + إنجليزي LTR) مع زر تبديل اللغة
- Layout مشترك مع Navbar + Footer متجاوب
- Skeleton loaders للتحميل

### 2. الصفحة الرئيسية (Landing Page)
- **Hero Section**: صورة طبية جذابة مع CTA للحجز
- **عن المركز**: تعريف بالدكتور أحمد يحيى ويارا محمد علي
- **الخدمات**: العلاج الطبيعي + التغذية + الاستشارات
- **أحدث المقالات**: عرض آخر 3 مقالات طبية
- **العروض الحالية**: عرض بصري للعروض (صورة + نص)
- **CTA حجز موعد**: زر بارز لحجز استشارة
- **Footer**: معلومات التواصل + روابط سريعة + وسائل التواصل

### 3. نظام المقالات
- **صفحة قائمة المقالات** `/articles`: عرض المقالات مع بحث وتصفية حسب التصنيف
- **صفحة المقال** `/articles/:slug`: عرض المقال الكامل مع صور + تعليقات + إعجابات
- عناوين URL صديقة لـ SEO باستخدام slugs
- بيانات تجريبية (Mock Data) لمقالات طبية

### 4. صفحة حجز المواعيد
- نموذج حجز يشمل: الاسم، الهاتف، وصف المشكلة، نوع الخدمة، التاريخ المفضل
- تأكيد الحجز مع Toast notification

### 5. تجهيز ربط PocketBase
- إنشاء service layer جاهز لربط PocketBase API
- تعريف أنواع البيانات (TypeScript types) لجميع الـ Collections: users, patients, articles, comments, likes, appointments, offers
- دعم `tenant_id` في كل model للبنية المستقبلية SaaS
- Mock data provider يمكن استبداله بـ PocketBase لاحقًا

### 6. SEO
- Meta tags ديناميكية لكل صفحة (title + description)
- بنية URLs نظيفة وواضحة

---

> **المراحل القادمة** (يمكن بناؤها لاحقًا):
> - نظام Auth مع أدوار (super_admin / doctor / patient)
> - لوحة تحكم الطبيب (CRUD كامل)
> - لوحة المريض (diet plan, workout plan, messages)
> - ربط PocketBase الفعلي
> - نظام ضغط الصور
> - Rich text editor للمقالات
